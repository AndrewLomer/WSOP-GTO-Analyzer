# WSOP-GTO-Analyzer
## Project Goal:
The goal of this prject is to create a program that looks at previous poker hands from WSOP World Championship tournaments and compares the player accuracy to a Game Theory Optimal(GTO) recommendations. It will then output the actual player accuracy from the profitable and unprofitable players, comparing them and seeing if GTO is actually a viable poker strategy.

## MVP
- Importing poker hands via CSV files from WSOP tournaments
- Organizing poker hands using Java classes
- Gathering GTO strategies from an external source
- Comparing actual player decisions with GTO recommendations
- Calculate the percentage of decisions that correlate with GTO strategy
- Display a summary of the results

## Future Plans
- Looking at larger WSOP datasets over a more extended period of time
- More detailed statistical analysis
- Analysis of different versions of poker other than Texas Hold'em
